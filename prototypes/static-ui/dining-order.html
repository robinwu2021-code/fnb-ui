混合布局（参考实机）：每个操作放哪

就地 作用对象就在眼前　竖条 只放「选中的这道菜」的操作　账单 整单操作：账单头小图标、账单底　更多 低频、桌台级

操作放哪理由
分类、搜索、点卡片加菜就地改的是菜单，眼睛正看着菜单
− 数量 +竖条顶加完菜手顺势落在竖条顶；账单行只留名称、份数、金额，一屏能多看几行
删除、规格做法、口味备注、单品打包竖条都只对选中的那道菜；新加的菜默认选中，一按即生效
赠菜、退菜、催菜 / 上菜竖条对选中行；按菜的状态置灰（没送厨不能退、不能催），授权类位置固定不易误点
临时菜竖条新增一行，和行操作在一起（实机同此）
挂单、取单、清空、整单备注、会员、优惠账单头作用于整单，跟账单放在一起；用小图标不占竖条
全单打包、打印预结单账单底收尾前看着金额用
送厨、结账账单底最大的两个按钮，收尾动作
换桌、并台 / 拆单、复制上一单、批量上菜更多竖条底「更多 ›」，一桌最多一两次

和上一版的区别：整单操作移出竖条（竖条只剩一种对象，按钮含义不会混）；数量步进移到竖条顶。账单左右可切换：实机多是账单在左、菜单在右（右手点菜）；App 现状账单在右，已有「账单在左 / 右」显示设置。

两种布局对照

分散（现状）中间竖条
找按钮跟着对象走：行操作在行上，整单在账单头固定一列，位置不变，熟手盲按
手的路径菜单 → 账单头 / 行尾 / 底部，来回跨菜单与账单之间，左右手都近
行操作直接点行上的 − / + / 催菜先选中行，再点竖条（多一步，但一组按钮通用）
占地不额外占宽约 84dp：菜品从 5 列变 4 列、账单略窄
可放下的按钮受各区域空间限制，次要操作进「更多」约 20 个一级按钮，退菜、并台、预结单不用再进「更多」
适合新手、触屏为主、桌少单简单高峰快餐 / 收银为主、熟练员工

建议：做成「界面显示」里的布局选项（默认分散），竖条按钮按权限显示、可在设置里排序。
