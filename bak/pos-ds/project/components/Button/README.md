# Button

POS 里的全部按钮，类名与 ai-shop `.sh-btn` 同名同义：胶囊形，一屏只有一个实心主操作。

- **形态四问**（沿用 ai-shop《规范·组件》）：只是换一屏或筛选，不用按钮；这一屏的主线，用实心 `sh-btn`；属于某一行的推进动作，用 `sh-btn--sm`；危险操作在页面上用 `sh-btn--danger`（描边墨字），二次确认的最后一步才用 `sh-btn--danger-solid`。
- **并排规则：** 主的实心，次的 `--soft`，「取消」用 `--muted`。结单区底部：挂单 `--muted`（只有图标）、送厨 `--soft`、结账实心。
- **尺寸：** 默认 `pos-ctl` 44；`--sm` 36（点按区靠 `.sh-hit` 补到 44）；`--lg` 52 给结账和支付确认。`--split` 让文字和金额分居两端。
- **调用方提供：** 2–4 字动词文案、可选前置图标；只有图标时必须给 `aria-label`。
- **POS 差异：** ai-shop 移动端的 `.sh-btn` 是块级、上下内边距撑高；POS 配方改为行内、固定高度，只在 `pos-v2` 作用域生效。
