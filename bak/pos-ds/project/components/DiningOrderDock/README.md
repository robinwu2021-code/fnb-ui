# DiningOrderDock

结单区（Z5 + Z2 + Z6）：顶部桌台订单条，中间订单明细，底部金额与操作。对应 ai-shop 候选 `DiningOrderDock`。

- **桌台订单条：** 桌号（`txt-display`）、桌区 · 人数 · 时长 · 单号；就餐方式分段；「桌台操作」菜单（改人数、换桌、并台、转菜、拆单、合单、预结单、清台）。并台后桌号写成「A08 + A05」。
- **明细：** 先「待下单」再「已下单」（带送厨时间）。点一行展开操作：待下单有步进器、备注、赠送、删除；已下单有催菜、赠送、退菜。转菜、拆单时每行前出现勾选框。
- **金额与操作：** 会员、优惠券、抹零三个色块筛选；小计（件数）、服务费（仅堂食）、打包费（外带外卖）、赠送、会员折扣、优惠券、抹零；虚线后是应收（`txt-hero`）。按钮：挂单 muted、送厨 soft（显示待下单数，没有时隐藏）、结账实心。
- 待下单不计入正式应收之外的任何已付状态；送厨后才进入「已下单」（FNB-D05）。
- **调用方提供：** 订单行、报价结果（分）、可用操作、当前桌台；金额以服务端报价为准（FNB-D04）。
