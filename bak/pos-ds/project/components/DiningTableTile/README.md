# DiningTableTile

桌台总览里的桌台卡：状态标签、桌号、人数 / 座位或预订信息、时长、应收。

- 状态靠底色块 + 状态文字两种方式表达：空闲 `sh-faint`、就餐中 `pos-info-tint`、待结账 `sh-warning-tint`、已预订 `sh-primary-tint`；被并台的桌显示「并入 A08」。
- 当前所在桌加 2px `sh-ink` 内描边，与状态分开表达。
- 选择目标模式（换桌、并台、转菜）下，不符合条件的桌禁用，顶部提示条写清要选什么。
- 总览顶部用 `sh-stat` 显示空闲 / 就餐中 / 待结账 / 已预订数量；桌区用 FilterChip 筛选。
