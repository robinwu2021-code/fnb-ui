# DiningMenuItem

菜单区（Z4）的菜品卡：整张卡是一个按钮，单击加一份，有规格时打开规格弹窗，长按看详情。

- `dn-grid` 用 `auto-fill`，最小列宽 `pos-tile-w` 136、卡片最小高 `pos-tile-h` 88、间距 `pos-gap` 8：1280 宽约 6 列，1024 宽 4–5 列。
- 已点：整卡变 `sh-primary-tint` 色块 + 右上 `dn-count`。沽清：`sh-faint` 底、`sh-chip--danger` 标签、不可点（点了提示「已沽清」）。限量：`sh-chip--warning` 写剩余数。
- 卡片 / 列表两种视图保留同一点击语义。首版纯文字卡；有商家实拍图时图片放在菜名上方，同一宫格内高度一致。
- **调用方提供：** 菜名、价格（分）、编号、标签、库存、已点数量。
