# DiningPosShell

POS 整页外壳：系统栏 + 三栏网格。L1 = 分类左（`pos-rail-w`）、宫格中、结单右（`pos-order-w`），间距 `pos-gap`。

- 三栏各自滚动；系统栏、桌台订单条、金额与操作区固定。
- 布局由设置决定：结单左 / 右 × 分类上 / 左 / 右，组件不变，只换网格模板。
- 应用宽度 < 1000px：分类横排在顶部，结单区收成底部条 + 抽屉；1000–1279px：结单区 320px。
- 在 b-app 里由 `sh-scaffold` 承担主题类名与安全区，`DiningPosShell` 只负责区域网格，作用域 `pos-v2`。
