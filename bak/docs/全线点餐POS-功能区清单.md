# 全线点餐 POS · 功能区清单（骨架第一步）

> 状态：草案 · 待确认 · 2026-10-23
> 目的：重新整理 UI 骨架。以**功能区**为单位组织功能清单，这一步只定「有哪些功能区」，每个区里的具体功能下一步再填。
> 来源：[功能清单与布局方案](全线点餐POS-功能清单与布局方案.md)（A–K 业务分组、Z1–Z7 布局区）、[详细功能清单](全线点餐POS-详细功能清单.md)、[点餐页功能区与方案](POS点餐页-功能区与方案.md)。

## 为什么要重新分

现在的 Z1–Z7 其实是**布局槽位**，不是功能区：

- Z4「内容区」在点餐页放菜品，在桌台页放桌台，在结账页放收款键盘，一个区承担了四件事。
- 功能清单按业务（A–K）分组，每条再标「Z4 Z7」这样的位置，没法回答「这个区一共要做哪些事」。

新的分法：

- **功能区 = 做一件事的界面单元**，按职责命名，功能清单挂在功能区下面。
- **布局槽 = 功能区放在哪**，沿用 Z1–Z7 和 L1–L6 开关，只管位置和尺寸。
- 一个功能区只属于一个工作台（或全局）；同一个功能区可以在不同布局里换槽位，但职责不变。

## 一、全局（每个工作台都在）

| 代号 | 功能区 | 职责（一句话） | 默认槽位 | 包含的业务（对应 A–K） |
|---|---|---|---|---|
| G1 | 身份与班次 | 谁在用、哪个门店、当前班次、时钟 | Z1 左 | A 开班状态、J |
| G2 | 工作台切换 | 在桌台 / 点餐 / 订单 / 班次之间跳转 | Z1 中 | — |
| G3 | 设备状态 | 打印、网络、钱箱的状态和入口；异常时变色 | Z1 右 | A 打印、网络、离线、钱箱 |
| G4 | 待办提醒 | 需要收银员处理的事：外卖待接、打印失败、催菜、待审批 | Z1 右 | H 外卖、F 出餐异常、J 审批 |
| G5 | 布局与风格 | 切换布局（导航区、详情区的位置）和风格（主题色、形状、深浅、密度）；入口在系统栏，内容在设置面板 | Z1 右 → X4 | K 设置 |

### G5 布局与风格的开关

| 类 | 开关 | 选项 | 影响范围 |
|---|---|---|---|
| 布局 | 导航区位置 | 上 / 左 / 右 | 所有工作台的 Z3（M2 分类、T1 桌区、O1 订单筛选）；结账、班次没有导航区 |
| 布局 | 详情区位置 | 左 / 右 | 所有工作台的 Z5 + Z6（M1、M5–M7、T3、O3、P1、S2 右栏） |
| 布局 | 组合 | L1–L6 | 两个开关的 6 种组合，默认 L1（导航左、详情右） |
| 风格 | 主题色 | 松绿、靛蓝、黛青、茶青、石墨、栗棕、绛红、墨黑（每套带一个辅助色，见 [配色方案](POS配色方案.md)） | 只换主色和辅助色；黑白灰和语义色不变 |
| 风格 | 形状 | B 端原生 / 微圆 / 方角 | 卡片、按钮、标签的圆角 |
| 风格 | 深浅 | 浅色 / 深色 / 跟随系统 | 全部颜色令牌 |
| 风格 | 密度 | 紧凑 / 标准 | 控件高度 44 / 48，菜品卡高度，间距 8 / 12 |

布局开关只影响收银平板；服务员手机、店长端、厨房屏只跟随风格。

## 九、需要先拍板的几处边界

1. **外卖是工作台还是面板。** 现在放在 X4 侧滑面板 + G4 提醒里。外卖单量大的门店可能要升为第 6 个工作台。
2. **结账是独立工作台还是点餐的浮层。** 现在按独立工作台（布局开关只影响 P1 详情区位置）。另一种做法是在点餐页上弹全屏收款。
3. **M6 和 P1 是否合并。** 两者都显示金额；现在分开是因为点餐时只看应收，结账时要看已收和待收。
4. **会员归属。** 识别会员放在 M6，会员详情放 X4 面板；充值不在收银平板做。
5. **桌台工作台与点餐工作台是否合并。** 有的产品把桌台图放在点餐页左侧。现在保持分开，靠 G2 切换。

确认这份功能区清单后，第二步按功能区逐个填：功能、优先级、授权、规则、原型屏。
