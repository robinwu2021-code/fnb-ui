# 全线点餐 POS · 布局与组件清单（按现有原型代码）

> 状态：2026-10-23 · 从 `prototypes/bapp/pos-ui.html`（已按模块拆分为 `ui/*.js`）逐项采集；取代按框架草图写的《组件清单》作为现行清单。
> 代码：`ui/core.js`（状态、数据、共用小件）· `ui/layout.js`（布局 `MODULES`、网格、系统栏）· `ui/modules/*.js`（9 个模块）· `ui/i18n.js`（英文）· `ui/app.js`（浮层分发、渲染、交互）· 样式 `proto.css` · 颜色 `pos-colors.css`（由 `tools/gen-colors.py` 生成）。

## 一、代码结构

| 文件 | 内容 | 注册 |
|---|---|---|

| `ui/modules/<模块>.js` | 该模块的工作台渲染、页内分区、浮层、交互 | `MODULES.<模块>.render / sections`、`OVL[键]`、`ACT[动作]` |
| `ui/i18n.js` | 英文：整句查表 → 规则替换 → 按「 · 」拆段查 | — |
