## 一、布局规范

### 1.1 画面

| 项 | 规定 |
|---|---|
| 基准设备 | 横屏收银平板 1280 × 800（原型按此 1:1）；最小 1024 × 768 |
| 纵向 | 系统栏 56 · 横幅（离线、异常时出现，平时 0）· 工作台（余下全部） |
| 外边距与栏间距 | 都等于 `--gap`（紧凑 8 · 标准 12）；画布色露出来就是栏与栏之间的缝，不画线 |
| 滚动 | 整页不滚动；只有面板主体（`.bd`）、导航栏、侧滑内容各自滚动 |

### 1.2 系统栏

左：店名 + 当班人 · 中：工作台页签 6 个（桌台、点餐、结账、订单、报表、设置）· 右：图标入口（打印、网络、外卖、会员、显示）+ 时间。

- 页签当前项 gray-200 块 + 墨字加粗；会员、菜品、班次不上页签，从设置菜单「管理」进入，进入后「设置」保持选中。
- 入口只放图标（36 × 36，热区 44），名称写在 `aria-label` 和 `title`；有状态的入口用状态图标（缺纸琥珀、离线红），计数用红色角标。
- 新增工作台：先问能不能放进设置菜单；页签不超过 6 个。

### 1.3 工作台：四种布局

| 代号 | 结构 | 用在 |
|---|---|---|
| W1 | 导航 · 内容 · 详情 | 桌台、点餐、订单、菜品、会员 |
| W2 | 账单清单（左 440）· 收款 | 结账 |
| W3 | 内容 · 详情 | 班次 |
| W4 | 导航 · 内容 | 报表、设置（设置 = 菜单 · 设置页两列） |

- 每个模块在 `ui/layout.js` 的 `MODULES` 里声明布局和栏宽，不在渲染里写死。
- 导航、详情的位置由「布局」L1–L6 决定（导航左 / 上 / 右 × 详情右 / 左）；导航在上时变横排资源栏。

### 1.4 栏宽

| 栏 | 宽 | 规则 |
|---|---|---|
| 导航 · 窄 | 104 | 图标 + 两字，或两字分类名（点餐分类） |
| 导航 · 中 | 128 | 桌区、时段、菜品、会员这类四字以内的菜单 |
| 导航 · 宽 | 160 | 报表、设置这类多字菜单 |
| 内容 | 余下（`1fr`） | 不设固定宽；宫格用 `auto-fill` 自适应列数 |
| 详情 | 360 | 结单区、桌台详情、订单详情、各详情表单 |
| 结账账单 | 440 | 只用于 W2 |

导航宽只用这三档；放不下就缩短文字或用双语两行，不新增档位。

### 1.5 面板骨架

所有栏都是面板 `sh-panel`：头 `.hd`（固定）· 主体 `.bd`（滚动）· 底 `.ft`（固定）。按用途六种骨架：

| 骨架 | 结构 | 写法 |
|---|---|---|
| P1 工具条 + 宫格 / 列表 | 头放 `sh-toolbar`（搜索占满，后跟筛选、分段）| `panel(head, body, foot, cls)` |
| P2 清单 + 白色窄底 | 头（标题 · 信息 · 快捷）· 主体 `dn-ledger` 浅灰清单 · 底 `dn-foot`（金额 + 操作） | `ledger(head, body, dueFoot(…))` |
| P3 详情表单 | 头标题 · 主体分组列表 · 底操作 | `side(head, body, foot)` |
| P4 统计 + 图表 | 指标行 `dn-kpis` · 图表网格 `dn-rgrid` | `panel` |
| P5 设置页 | 左菜单（资源栏 + 分组小标题）· 右设置页 `sh-panel--page` | 设置模块 |
| P6 浮层 | 弹窗 `sh-dialog`（≤ 560，宽版 760）· 侧滑 `sh-sheet`（右侧 480） | `OVL[键]` |

- 面板里分段用区块 `dn-block` + 区块标题 `dn-sec`，段间 16；字段标签用 `sh-gt`。
- 主操作放底部，一屏实心主按钮最多 1 个。
- 金额类面板（结单、结账、订单详情、桌台详情、钱箱）一律用 P2：清单是唯一的灰色区域，底部白色、不加线。

### 1.6 间距

| 令牌 | 紧凑 | 标准 | 用在 |
|---|---|---|---|
| `--gap` | 8 | 12 | 栏间、卡片间、控件间 |
| `--pad` | 12 | 16 | 面板、卡片内边距 |
| 区块间 | 16 | 16 | `dn-block` 之间、设置页分块 |
| `--px` | 16 | 20 | 按钮左右内边距 |

只用 2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 / 24 这几个数；组件内部的小间距（图标与文字 6）不另设令牌。

## 二、形状规范

### 2.1 圆角：框架、按钮两套

| 变量 | 管什么 |
|---|---|
| `--rc` | 面板、卡片、弹窗外框（弹窗再加 4） |
| `--rt` | 卡内块：菜品卡、桌台卡、订单卡、清单、图片（比 `--rc` 小一档，保持同心） |
| `--rb` | 按钮、标签、筛选 |
| `--rk` | 输入框、分段、选项、按键、步进器 |

| 框架档 | rc / rt | | 按钮档 | rb / rk |
|---|---|---|---|---|
| 方 | 2 / 2 | | 方 | 2 / 2 |
| 小 | 6 / 4 | | 小圆 | 4 / 4 |
| 中 | 10 / 8 | | 圆角 | 8 / 8 |
| **大（默认）** | **14 / 10** | | **圆角（默认）** | **8 / 8** |
| 特大 | 20 / 14 | | 胶囊 | 全圆 / 12 |

推荐组合（「形状方案」）：利落 小 + 小圆 · **标准 大 + 圆角（默认）** · 柔和 特大 + 胶囊 · 混搭 中 + 胶囊 · 方正 方 + 方。规则：容器比控件圆或相等，不能反过来。

### 2.2 尺寸

| 项 | 紧凑 | 标准 |
|---|---|---|
| 控件高 小 / 中 / 大 | 36 / 44 / 52 | 40 / 48 / 56 |
| 列表行高 | 44 | 52 |
| 菜品卡、桌台卡最小高 | 84 | 100 |
| 触控热区 | 不小于 44 × 44；小号控件用 `::before` 补足（`sh-hit`） | 同左 |
| 桌台卡 | 最小宽 124，自适应列 | |
| 菜品卡 | 最小宽 140，自适应列 | |
| 订单卡 | 最小宽 200，自适应列 | |

### 2.3 字

| 档 | 字号 / 字重 | 用在 |
|---|---|---|
| `--fs-2xl` | 32 / 700 | 应收、应付、实收 |
| `--fs-xl` | 22 / 600–700 | 统计数字、订单卡金额 |
| `--fs-lg` | 18 / 600–700 | 标题、桌号 |
| `--fs-md` | 15 / 600 | 按钮、菜名 |
| `--fs` | 14 / 400 | 正文 |
| `--fs-sm` | 13 / 400 | 次要信息、费用行 |
| `--fs-xs` | 12 / 400–600 | 标签、区块标题、双语第二行 |

不用 11 号及以下。数字一律等宽（`tabular-nums`）。字体：西文 Inter（可选 Roboto、Noto Sans、Manrope、IBM Plex Sans），中文思源黑体。

### 2.4 图标

Lucide，线宽 1.75；尺寸 14（状态标签内）· 16（行内、费用行）· 18（入口、按钮、优惠行）· 20 以上只用于空状态。图标按钮必须有 `aria-label`；不用字符（✓ ✕ ›）当图标，`›` 只用于「进入下一级」。

### 2.5 形态：用色块，不用线框

| 状态 | 形态 |
|---|---|
| 卡片未选 | 浅灰块 `--sh-wash` |
| 选中（导航、页签栏、分段、筛选、选项、支付方式、当前桌、选中的订单卡 / 活动卡） | **gray-200 块 + 墨字加粗** `--sh-sel-bg / -fg`；不用墨底 |
| 已点的菜 | 同选中：gray-200 块 `--sh-pick` + 墨色份数角标 |
| 列表、表格当前行 | gray-100，不加竖条 |
| 状态卡（桌台、订单） | 整块状态块：常态 30%、要处理 60%、空闲 / 关闭浅灰 |
| 勾选框、开关 | 未选 gray-150 实心块 / 灰轨道；选中主色（墨）+ 白勾，是控件不是按钮 |
| 危险按钮 | 浅红底红字；实心红只用于不可撤销的最终确认 |

不画描边、不加阴影。允许的线只有三种：侧滑页签的 2px 底线（区分「换页」和「筛选」）、清单里已下单行之间的 2px 白缝、键盘焦点环。

## 三、色系规范

### 3.0 墨只做两件事

**墨（gray-900）只用于正文和主按钮。** 选中、当前项、已点一律不用墨底，改用灰阶里深两档的块：

| 层 | 墨黑取值 | 用在 |
|---|---|---|
| 画布 | gray-50 | 栏与栏之间 |
| 面板 | 白 | 面板、卡片、弹窗 |
| 浅块 | gray-50 | 未选的卡、清单底、输入框、muted 按钮 |
| 深一档 | gray-100 | 列表 / 表格当前行、悬停 |
| **选中** | **gray-200 + 墨字加粗** | 导航、页签、分段、筛选、选项、支付方式、当前桌、选中的卡、已点的菜 |
| 墨 | gray-900 | 正文、标题、金额；主按钮（白字）；Toast 和操作菜单的反色面 |

一屏只有一个墨色块（主按钮），眼睛找「下一步」只看它。选中靠「比周围深两档 + 加粗」辨认，不靠反白。份数角标、勾选、开关的开启态用主色（墨黑皮肤下即墨），它们是标记和控件，不是按钮。其他皮肤：选中 = 主色浅底 + 主色字，主按钮 = 主色实心。

### 3.1 默认：黑白灰色系

`data-tone="quiet"`（默认）；原配色保留为「多色」`data-tone="color"`。色系和皮肤是两个开关，互不影响。

1. **黑白灰承担结构和常态。** 画布 gray-50、面板白、浅块 gray-50 / gray-100、字墨 gray-900 / 次要 gray-600。
2. **颜色只给要人处理的事：** 琥珀 = 待处理，红 = 异常。一屏看到颜色就该动手。
3. **常态按明度分层：** 进行中墨 · 等待中 gray-700 · 已完成 / 变更标记 gray-600 · 已关闭 gray-500。
4. **一种颜色只用一档：** 图标和文字同档。
5. **颜色从不单独表达信息：** 状态一律「图标 + 文字」。

### 3.2 角色（组件只用这些令牌）

| 角色 | 令牌 | 墨黑取值 |
|---|---|---|
| 画布 | `--sh-bg` ← `--c-canvas` | gray-50 |
| 面板、卡片 | `--sh-card` ← `--c-surface` | 白 |
| 浅块 / 深一档浅块 | `--sh-wash` / `--sh-wash-strong` | gray-50 / gray-100 |
| 已点 | `--sh-pick` ← `--c-pick` | gray-200 |
| 选中 | `--sh-sel-bg` / `--sh-sel-fg` | gray-200 / gray-900 |
| 字 | `--sh-ink` / `--sh-sub` / `--sh-disabled` | gray-900 / gray-600 / gray-400 |
| 主色（随皮肤） | `--sh-primary` · `-tint` · `-text` · `--sh-on-primary` | 墨 |
| 状态组 | `--c-st-<组>-dot / -text / -tint / -block / -block-strong`，经 `stv()` 写成 `--d --t --b --bk --bks` | 见 3.3 |
| 优惠金额 | `--sh-saving` ← `--c-saving` | 墨（多色下成功绿） |
| 实心色上的字 | `--sh-on-solid` | 白 |
| 遮罩 | `--sh-scrim` | rgba(12,14,18,.45) |

组件里不写色值、不写 `color-mix`；需要新颜色先在 `tools/gen-colors.py` 里加角色，再生成。

### 3.3 状态组（黑白灰）

| 组 | 颜色 | 形式 | 例 |
|---|---|---|---|
| 待处理 | 琥珀 700 / 底 200 | chip | 待结账、待点餐、催菜中、超时未上菜 |
| 异常 | 红 700 / 底 200 | chip | 接单超时、支付失败、打印失败 |
| 进行中 | 墨 | dot | 用餐中、制作中 |
| 等待中 | gray-700 | dot | 待取餐、配送中、支付中 |
| 已完成 · 变更标记 | gray-600 | dot | 已上菜、已支付 · 补打、改价、赠送 |
| 预约 · 暂存 | 墨字 gray-150 底 | chip | 已预订 · 挂单、待下单 |
| 已关闭 | gray-500 / 600 | dot | 已取消、停用 |

### 3.4 允许的例外（保留颜色）

| 位置 | 颜色 | 理由 |
|---|---|---|
| 支付方式图标 | 品牌色（微信绿、支付宝蓝…） | 靠品牌色认支付方式 |
| 平台标识 `dn-plat` | 品牌色（美团黄、抖音黑、快手橙、小红书红） | 靠品牌色认平台 |
| 菜品照片 | 原图 | 内容本身 |
| 收款完成、已收齐 | 成功绿 | 一次性结果 |
| 报表环比 | 涨绿跌红 | 数据图表 |
| 主题皮肤的主色 | 皮肤色 | 门店选择，只出现在主按钮、选中等固定位置 |

### 3.5 对比度底线

正文与背景 ≥ 4.5:1；图标、状态圆点、控件边界 ≥ 3:1；警告标签文字（琥珀 700 / 200 = 4.51）不小于 12px。新增颜色由生成器自检，不过线不出图。

## 五、未解决

1. **键盘与焦点（R10）**：原型的可点元素多是 `span`，没有焦点和焦点环。正式实现时：可点元素用 `button` 或带 `tabindex`，焦点环 2px 墨色、外扩 2px。
2. **深色模式**：不做（2026-10-24 决定）。夜间营业靠屏幕亮度，不另做一套颜色。
