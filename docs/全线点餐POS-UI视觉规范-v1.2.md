## 四层背景

| 层 | 颜色 | 用途 |
| --- | --- | --- |
| 画布 | #F3F5F4 | 只露在外边距和区域间隙，让白色面板有边界 |
| 内容面板 | #FFFFFF | 导航、主工作区、右侧账单主体 |
| 局部内容块 | #F6F8F7 | 桌台卡等独立可选对象，不能铺满整个面板 |
| 操作底栏 | #F0F5F2 | 右侧金额摘要与结账操作，浅绿灰底形成明确落点 |

外边距与区域间隙24dp。主要区域圆角8dp，卡片4dp，按钮12dp。保留容器比按钮更平直的关系，不恢复大圆角卡片套卡片。

主内容区、账单区有独立白色底；底部空余空间属于画布或具体面板，不再跨区域连成白色长条。右侧操作底栏与账单主体连接处为直边，底部两角继承面板8dp圆角。

底栏固定在账单底部，包括金额和主操作；长账单只滚动上方主体。窄屏摘要与操作面板继续沿用操作底色，主操作不能漂浮在无归属的白底中。

不增加灰色线框。默认通过底色差和间隙划分；确实需要提升浮层识别时，面板可用5%中性灰柔影、Y4、模糊20，不同时增加描边。不以阴影替代焦点或选中标记。

## 检查要求

缩小看画面时能明确区分导航、主工作区、账单主体及操作底栏；正常卡片可识别，选中卡片更突出。底栏应与内容形成层次，但不能比主按钮更抢眼。中英文、字号及业务流程不因背景调整而变化。

当前为静态方向样张，使用本机替代字体；未接入Android运行时代码，尚需真机检查浅色层次与屏幕亮度适应性。
