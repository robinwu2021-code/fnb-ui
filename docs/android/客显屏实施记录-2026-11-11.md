# 客显屏实施记录（2026-11-11）

客显屏是收银机上面向顾客的副屏，例如双屏收银机的顾客屏。它只显示内容，顾客不能在上面操作，显示什么全部由本机状态决定。原型中的设置项是「显示订单明细（开）」和「空闲时轮播（开）」（见 `prototypes/bapp/ui/modules/settings.js`），这里都已实现。

## 显示内容

| 状态 | 什么时候出现 | 显示内容 |
|---|---|---|
| 点单 | 收银员当前选中的桌台正在用餐且有菜品 | 门店名、桌台号；左侧逐行列出菜品、规格、数量和金额，赠送的菜显示「赠送」；右侧显示小计、优惠、服务费和当前合计 |
| 结账 | 结账页打开时 | 「当前合计」改为「应付」，并显示收款方式；现金收款时显示实收和找零（实收不足时不显示找零） |
| 收款成功 | 结账成功后显示 8 秒 | 「收款成功」、收款方式与金额、找零（大于 0 时）、「谢谢惠顾，欢迎再次光临」 |
| 空闲 | 没有选中桌台，或桌台已结账、没有菜品 | 轮播推荐菜品（有图片的优先、不含沽清的菜，最多 8 道，5 秒一页）；关闭轮播时只显示「欢迎光临」 |

## 设置（本机）

入口：「系统管理 → 设备与系统 → 客显屏」。

- **检测到的副屏：** 显示检测到的副屏名称和分辨率。副屏插上或拔下后，这里会立即刷新。
- **三个开关：**
  - 启用客显屏。
  - 显示订单明细：关闭后只显示合计。
  - 空闲时轮播。

  三个开关都保存在本机显示偏好中（DataStore），不属于门店配置，也不会同步到其他设备。
- **预览：** 把 1280×800dp 的副屏画面按比例缩小显示，与副屏实时同步。没有副屏时也可以用它查看效果。

## 实现要点

- **显示规则：** `core/model/CustomerDisplay.kt` 中的 `CustomerDisplayRules.view()` 是纯函数，输入门店数据、当前桌台、结账阶段、两个开关和当前时间，输出要显示的内容。
- **结账阶段：** 由 `AppContainer.customerStage` 保存，结账页负责写入：
  - 打开结账页时写入「结账」（收款方式和实收随输入更新）。
  - 收款成功写入「收款成功」。
  - 离开结账页时，如果仍在结账阶段，就回到普通浏览。
- **副屏：**
  - `CustomerDisplayHost` 在 `MainActivity` 中启动。它查找系统中的副屏（`DisplayManager.DISPLAY_CATEGORY_PRESENTATION`），用 `Presentation` 显示客显画面，并保持副屏常亮。
  - 副屏插上或拔下时自动显示或关闭；关闭「启用客显屏」后也会关闭。
- **画面：** `feature/customer/CustomerDisplay.kt` 中的 `CustomerScreen` 使用当前皮肤配色，字号较大；每秒刷新一次，用于致谢页计时和轮播翻页。

## 验证

- **单元测试：** 新增 3 项，覆盖：
  - 跟随当前桌台显示明细。
  - 结账阶段以结账桌台为准，找零计算正确，实收不足时不显示找零。
  - 关闭明细后仍显示合计。
  - 致谢页 8 秒后消失。
  - 轮播不含沽清的菜、最多 8 道；关闭轮播时为空；没有门店数据时显示空闲。

  全部 168 项通过。
- **模拟器：** 在 emulator-5600 上用模拟副屏验证，命令为 `adb shell settings put global overlay_display_devices 1280x800/160`。
  - A08 点单时，副屏显示 10 行菜品、小计 ¥190.00、服务费 ¥9.50、当前合计 ¥199.50。
  - 进入结账、现金输入 200 后，显示应付 ¥199.50、实收 ¥200.00、找零 ¥0.50。
  - 收款后显示「收款成功 · 现金 ¥199.50 · 找零 ¥0.50」，约 8 秒后进入轮播（酸梅汤、小炒黄牛肉、宫保鸡丁等）。
  - 设置页能识别「Overlay #1（1280×800）」，预览正常缩放。
  - 关闭「启用客显屏」后，副屏不再显示客显画面（变为系统默认的镜像主屏）；重新打开后恢复。
  - 没有崩溃。
- **模拟器注意事项：** 模拟副屏以小窗形式叠在主屏左上角，会挡住主屏左上角的点击，例如设置按钮。真实双屏设备没有这个问题。测试完成后可以用 `settings put global overlay_display_devices null` 移除模拟副屏。

## 仍未覆盖

- **局域网客显：** 不支持把独立平板或网页作为客显屏，例如通过主副 POS 通道推送。目前只支持本机副屏。
- **顾客确认：** 储值付款时由顾客在客显屏上确认，以及扫码收款时在客显屏展示收款码，都没有做。目前只显示内容，没有可交互的确认流程。
- **轮播内容：** 不能自定义轮播内容，例如门店广告图、活动海报；目前固定使用菜品。
- **实机：** 未在真实双屏收银机（如商米 T2）上验证。
