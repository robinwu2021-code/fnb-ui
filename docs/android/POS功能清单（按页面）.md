# 餐饮 POS 功能清单（按页面）

更新：2026-11-05（阶段一离线模式完成后）。范围：Android 工程 [bak/pos-android](../../bak/pos-android/README.md)（分支 `android-ui-v3`）对照 v3 原型与 [页面实施与验收清单](页面实施与验收清单.md)。

状态说明：

| 标记 | 含义 |
| --- | --- |
| ✅ | 已实现，可在模拟器操作；数据为本地演示 |
| ◐ | 有入口或部分实现，只给演示提示，未形成完整流程 |
| ○ | 未实现 |

「已实现」只代表界面与本地状态流转可用。送厨、收款、打印、会员、优惠等都没有接真实服务。
