| 交班 | ✅ | — |
| **日结**：汇总当前营业日 | ○ | ★ |

日结规则：
- **前置条件：** 有未结账的用餐中订单、或有结果未知的打印任务时，不能日结。
- **汇总内容：** 营业额、实收、单数、客单价、优惠、退赠、各收款方式、会员充值。
- **完成后：** 生成日结单进入打印队列，开启新的营业日，记录可在历史日结中查看。

## 实现约定

- **事件：** 会员、优惠、日结这类写入，都和其他营业写入一样进入命令日志并带事件。
- **主机执行：** 副 POS 绑定会员、选择活动时经主机执行。新建会员、充值、活动配置、日结只能在主 POS 上做。
- **金额：** 一律用 Long 分；折扣率用万分比，按整数四舍五入。
- **旧数据：** 旧订单的会员开关和优惠券、活动开关继续可用。旧收款没有订单快照，只计入营业额，不计入菜品报表。

## 本轮实现与验证（2026-11-11）

**入口**

| 功能 | 位置 |
| --- | --- |
| 会员、优惠 | 点餐页账单区的「会员」「优惠」按钮；结账页「优惠与资产」 |
| 会员管理、优惠活动 | 系统管理 → 会员与营销 |
| 计价与收款设置 | 系统管理 → 门店与营业 → 计价与会员、收款方式 |
| 出菜看板、报表与日结 | 页头图标；窄屏收在「更多」菜单里 |

**规则要点**
- **计价顺序：** 会员折扣 → 主管折扣 → 活动折扣 → 满减。优惠合计不超过小计，服务费按小计计算。
- **快照：** 费率在开台时、活动在选用时存成快照，之后改设置不影响已开的订单。
- **储值支付：** 扣本单会员的余额，同时累计积分、消费金额和到店次数，并记流水；支付事件同时计入该会员的聚合。
- **订单快照：** 结账时保存订单快照，作为报表依据。
- **日结：** 有未结账订单或结果未知的打印任务时不能日结。日结生成日结单，新营业日从日结时刻的下一毫秒开始，与上一日的统计区间不重叠。
- **副 POS：** 绑定会员、选择活动经主机执行；新建会员、充值、活动配置、日结只能在主 POS 上做。

**验证**
- **单元测试：** 137 项通过，其中 `DailyOpsTest` 7 项，覆盖：
  - 费率快照、会员全流程、余额不足
  - 活动门槛、整单折扣互斥、活动快照
  - 停用的收款方式被拒绝
  - 报表与日结
  - 旧收款不计入明细，旧版优惠开关仍然有效
- **模拟器（主 POS）：**
  - 新建会员并充值 500 元。
  - A06 绑定会员、选用满 100 减 5，结账页逐项显示会员优惠 −6.60、活动优惠 −5.00。
  - 储值支付 ¥127，会员余额变为 373 元、积分 127，流水记录正确。
  - 出菜看板能列出待上菜并一键上菜。
  - 报表显示营业额、收款方式、菜品排行和分类，旧收款单独提示。
  - 有 3 桌未结账时日结被拦截。
  - 全程没有崩溃。

**开发中修复：** 日结时刻恰好有收款时，这笔收款会被重复统计进前后两个营业日。现在新营业日从日结时刻的下一毫秒开始。
