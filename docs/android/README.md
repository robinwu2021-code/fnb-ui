## 预览与校验

仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes
node --test prototypes/v3/*.test.mjs
```

原型配置和订单主要保存在页面会话中，刷新恢复示例；显示偏好和桌台位置保存本机。登录、注册、送厨、收款核对、打印、会员与优惠均不代表真实服务已接通。正式开发必须将这些操作接入明确的业务契约。

阅读优先级：用户后续确认 → 本目录架构与契约 + 组件规范 → v3 当前共享组件 → 历史文档。本文所列 Android 分层、事件及服务方法为实施方案，未声明它们已存在于代码中。
