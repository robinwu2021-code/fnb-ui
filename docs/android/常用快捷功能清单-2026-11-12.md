# 餐饮 / 零售常用快捷功能清单（2026-11-12）

> 依据 Android POS 当前代码（`android-phase2b`）盘点：每项写清**在哪里点、做什么**。「建议补充」是盘点中发现还缺、值得做的，未实现。

## 一、两业态共用

| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 切换门店 | 页头左上角门店名 | 直接回选店页，不用退出登录 |
| 锁屏换人 | 页头锁形图标（设了员工才有） | 当前员工下岗，下一位用 PIN 上岗 |
| 开钱箱 | 页头钱箱图标；零售收银台「更多」 | 手动弹钱箱（记录操作人）；现金收款 / 退款自动弹 |
| 交班 | 页头交班图标 | 当班汇总 → 填实盘 → 平账打印交班单 |
| 报表与日结 | 页头报表图标 | 当前营业日 / 近 7 天 / 历史日结；多店账号有「商户汇总」 |
| 打印队列 | 页头打印机图标 | 看失败 / 结果未知的单，补打、改投、人工核对 |
| 同步状态 | 页头云图标 | 离线待补传的收款与送厨 |
| 中英文切换 | 页头语言图标 | 一键切换界面语言 |
| 显示设置 | 页头最右图标 | 字号、密度、图片开关、客显等 |
| 主管授权 | 退菜 / 赠送 / 折扣 / 改价 / 无单退货弹窗 | 主管输姓名 + PIN 当场授权，不用切账号 |
| 键盘「下一项」 | 所有表单 | 软键盘按「下一项」逐个填下去，最后一项收起键盘或直接提交 |

## 二、餐饮

### 桌台页
| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 按区域 / 状态筛桌 | 左侧区域栏、顶部状态胶囊（空闲 / 用餐中 / 已预订 / 已结账 / 待清台） | 一眼找到空桌或待清台 |
| 搜索桌号 | 桌台页右上搜索框 | 输入桌号直接定位 |
| 卡片 / 平面位置视图 | 「卡片 · 平面位置」切换 | 按实际布局看桌 |
| 开台点餐 | 选中空桌 → 「开台点餐」，选人数 | 开台后直接进点餐 |
| 继续点餐 / 结账 | 选中用餐中的桌 → 右下按钮 | 不用先进点餐页 |
| 打印预结单、整单备注、换桌、并台 | 右侧「服务快捷入口」 | 常用桌台操作一屏完成 |
| 清台 | 已结账的桌 →「进入清台」→「清台完成」 | 两步回到空闲 |
| 预订管理 | 「预订管理」 | 记预订、到店一键开台 |

### 点餐页
| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 热销分类 | 左侧第一栏「热销」 | 常点菜放最前 |
| 搜索菜品 | 搜索框，支持菜名、拼音、英文、编号 | 不翻分类直接找 |
| 口味筛选 | 「辣味 / 素食」标签 | 快速缩小范围 |
| 点卡片加菜 | 点菜品卡片；有规格的弹规格选择 | 一点即加，卡片角标显示已点数 |
| 加减份数 | 账单行的 − / + | 改数量不用删重点 |
| 菜品备注 / 整单备注 | 行上「+ 备注」、更多操作 | 忌口、口味随单送厨 |
| 送厨 | 底部「送厨 · N」 | 新加菜一次送出，按档口拆单 |
| 清空新加 | 「新加 · 待送厨」行的「清空」 | 撤掉还没送厨的菜 |
| 挂单 / 取单 | 账单区「挂单」，取单到当前桌 | 菜先挂起，之后并入任意在用桌 |
| 催菜 / 已上菜 | 已下单行的「催菜」「已上菜」；「批量」一次处理多道 | 前厅跟进出菜 |
| 换桌 / 拆单 / 并台 | 点餐页「换桌」、更多操作 | 不回桌台页就能调整 |
| 会员 / 优惠 | 账单区「会员」「优惠」 | 绑会员享折扣、选满减活动 |
| 摆放模式 | 菜品区右上布局按钮 | 切换卡片大小 / 列表 |

### 结账页
| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 快捷实收 | 「刚好 / ¥20 / ¥50 / ¥100」+ 数字键盘 | 现金一点填好，自动算找零 |
| 小票预览 / 打印预结单 | 结账页右上 | 给客人核对 |
| 继续加菜 | 「继续加菜」 | 结账前临时加菜不丢账单 |
| 退赠折扣 | 「主管授权 · 退赠折扣」 | 退菜、赠送、整单折扣一处授权 |

### 出菜页 / 厨房
| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 出菜看板 | 页头出菜图标 | 待上菜、超时（≥15 分钟）、催菜中分组 |
| 厨房屏 | 副机设为厨房屏 | 接单 / 制作 / 完成；未收到可一键改打纸单 |

## 三、零售

### 收银台
| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 扫码枪直扫 | 收银台、订单页、商品页、库存页都接收 | 不用先点输入框；输入框有焦点时不吞按键 |
| 一码多认 | 扫码自动识别 | 商品条码、店内码、PLU、称重码（带金额重量）、会员码 M 开头、价签 EAN-13 |
| 一码多品 | 同码多个商品时弹出选择 | 不会扫错 |
| 数量倍数 | 「× 2 / × 3 / × 5」后再扫 | 一次加多件 |
| 再来一件 / 撤销 | 扫码框下「刚扫」行 | 重复加、误扫立刻撤 |
| 常用 / 分类格子 | 无码商品点格子 | 散装、自制品快速加 |
| 称重 | 点称重商品，接电子秤自动读数（稳定才可加），未接秤手输或 0.25 / 0.5 / 1 kg 快捷重量、去皮 | 散称一步到位 |
| 购物袋 | 购物车上方「+ 袋（中）」 | 一点加袋 |
| 查价 | 「查价」开关 | 只看价格库存，不进购物车 |
| 临时商品 | 「临时商品」 | 未建档商品手输名称和价格 |
| 识别会员 | 扫会员码或输手机号；可当场新建 | 会员价、积分、储值 |
| 行操作 | 点购物车行：改价（授权）、备注、赠送、删除 | 单行处理 |
| 整单折扣 / 优惠活动 | 购物车「整单优惠」区（收款页也能改） | 主管授权打折、选活动 |
| 挂单 / 取单 | 「挂单」「取单 · N」 | 客人去拿东西先挂起；取单时当前车自动挂起 |
| 现金刚好 / 扫码收款 | 收款按钮上方两个快捷键 | 不进收款页直接收 |
| 快捷实收 | 收款页数字键盘 | 实收、找零 |
| 下一位 | 收款完成弹窗 | 清车开始下一单 |
| 购物车草稿 | 自动 | App 被杀、重启后恢复未收完的车 |
| 换货抵扣 | 订单页换货后自动带到收银 | 新商品补差价或退差价 |

### 订单页
| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 扫小票单号 / 会员码 | 直接扫 | 定位原单 |
| 状态筛选 | 全部 / 已退等胶囊 | 快速找单 |
| 补打小票 | 订单详情「补打」 | — |
| 退货 / 换货 / 无单退货 | 详情页按钮，或列表「退货」 | 选件数 → 原因 → 回库或报损 → 原路退款 |

### 商品页
| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 就地改价 | 选商品 → 右侧售价 → 保存 | 改完自动进待打价签 |
| 价签批量打印 | 「价签」：扫码或输名加入、全选、选模板（60×40 / 40×30 / 货架条） | 发标签机 TSPL |
| 低库存 / 临期提醒 | 「库存」子页 | 一眼看要补货、要处理的商品 |

### 库存页
| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 扫码加行 | 单据内直接扫 | 入库、盘点、报损、调拨都可扫 |
| 一键补低库存 | 入库单「低库存，建议补货」胶囊 | 缺货商品一点加入 |
| 一键处理临期 | 报损「临期」 | 临期商品批量报损 |
| ± 步进 | 单据行 − / + | 改数量 |

### 后台批量整理（系统管理）
| 快捷功能 | 入口 | 作用 |
|---|---|---|
| 批量调价 | 商品资料「批量调价」 | 按百分比调价，按角取整，零售进待打价签 |
| 删除商品 / 删除桌台 | 商品资料「删除商品」、桌台管理「删除桌台」 | 建店后清掉演示资料；在用的不能删 |

## 四、建议补充（未实现）

| 业态 | 建议 | 理由 |
|---|---|---|
| 共用 | 实体键盘快捷键（F1 收款、F2 挂单、F3 取单、F4 查价、Esc 返回、Del 删最后一行） | 零售收银机多配实体键盘，手不用离开键盘 |
| 共用 | 最近一单补打 / 撤销最近一单（授权） | 打印失败或刚收错时最常用 |

| 餐饮 | 菜品长按快速改份数 / 半份 | 大桌点同一道菜多份时省点击 |
| 餐饮 | 复制上一桌 / 套餐一键下单 | 团餐、固定套餐场景 |
| 餐饮 | 桌台页「一键清所有已结账桌」 | 晚市翻台高峰 |
| 零售 | 扫码框输入「3*」前缀定数量 | 和 × 2/3/5 互补，适合任意数量 |

| 零售 | 收款页「整单抹零到元」 | 小店常见习惯 |
| 零售 | 商品格子按销量自动排「常用」 | 现在常用是固定配置 |
