# 桌台流转、送厨和挂单事件接入

日期：2026-11-10。继续使用本地命令事务，保持现有页面操作。

| 操作 | 事件 |
| --- | --- |
| 换桌 | TableChanged |
| 并台 | TableMerged |
| 拆单 | OrderSplit |
| 挂单 | OrderHeld |
| 取单 | OrderRetrieved |
| 送厨 | KitchenSubmitted |

事件、Inbox回执、业务快照及命令流版本同一SQLite事务保存。新增公共事件字段：

- `affectedTables`：所有发生桌台或订单变更的桌台及结果订单，包含移动操作双方。
- `addedHeldTickets` / `removedHeldTicketIds`：挂单新增快照及被取回票据编号。
- `addedPrintJobs`：本次新增打印任务快照，不代表设备已经打印。
- `addedOutboxItems`：本次新增的既有离线待发任务。

离线送厨仍按现有Queued规则运行；KitchenSubmitted表示本地提交，不代表真实厨房已接收。重复取单被业务规则拒绝，无新菜品的重复送厨不产生新事件。事件不能被直接重放为出纸指令。
