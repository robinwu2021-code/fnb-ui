# Android POS 剩余任务清单（2026-11-11）

基线：`android-ui-v3` 分支 `4b57e69`，168 项单元测试通过。本清单汇总以下文档中尚未完成的事项：

- [POS交接文档（未完成部分）](POS交接文档（未完成部分）.md)
- 各实施记录的「仍未覆盖」
- [厨房送达目标与多设备方案](厨房送达目标与多设备方案-2026-11-11.md)

按前置条件分为五类：

- **A 类：** 现在就能在本地开发。
- **B 类：** 需要真实硬件。
- **C 类：** 需要后端服务。
- **D 类：** 需要门店或业务做决定。
- **E 类：** 发布前的质量工作。

## 本轮已完成（供对照）

- **分档口：** 送厨按档口拆卡；厨房单按档口拆分，并路由到各档口的打印机。
- **送达规则：** 档口可选出单方式（必须送达哪一路）；厨房屏超时后可以改打纸单或人工确认。
- **打印机：** 备用打印机（确定没打出时自动改投，另有手动改投）；多打印机副本。
- **客显屏：** 在本机副屏上显示点单、结账找零、收款致谢和空闲轮播。

## B. 需要真实硬件

| # | 任务 | 需要 | 验收 |
|---|---|---|---|
| B1 | 网口小票机核对 | 一台门店实际使用型号的网口 ESC/POS 打印机 | 中文模式（`FS &` / GB18030）、切刀指令 `GS V B`、状态字节的位定义；不回报状态的型号关闭状态查询 |
| B2 | 双屏收银机客显 | 真实双屏机，例如商米 T2 | 能识别副屏，插拔正常，长时间亮屏，画面比例和字号合适 |
| B3 | 其他打印连接方式 | USB、蓝牙打印机，或厂商云打印 SDK | 与网口方式使用同一套打印状态（已发送、结果未知等） |
| B4 | 真实故障验收 | 断电、拔网线、磁盘写满 | 恢复后数据不丢、不重复出单、不重复收款 |

## E. 发布前质量

- **回归测试：** 旋转、分屏、后台恢复、键盘遮挡，以及窄屏下的界面检查。
- **金额大单：** 大单溢出的边界验收，规则已有单元测试。
- **事件与快照：** 事件覆盖还不完整，目前不能只从事件重建门店；快照尚未全部拆成实体存储。
- **恢复界面：** 坏库或未知版本时的恢复界面需要完善。
- **发布素材与配置：** 处理演示图片、User-Agent、演示账号，确定应用签名和升级方案。

## 建议顺序

1. **A1 同档口多屏分派：** 方案已定，不依赖外部，可以直接开始。
2. **A4、A5、A12：** 都是小项，适合一起做，补齐本轮功能的显示、配置和英文翻译。
3. **B1 真实网口打印机核对：** 打印链路现在最大的风险在这里。拿到打印机就可以做，与上面的任务并行。
4. **A2、A3：** 改善厨房体验。
5. **A6、A7：** 增强客显屏，按门店需求决定。
6. **A8、A9、A10：** 主副 POS 增强。A10 是 N9 的前置，建议在后端联调前完成。
7. **C 类：** 等后端接口和联调环境就绪后按 N8 → N9 → N10 推进。D1–D4 需要在 N8 之前确定。
8. **A11、E 类：** 按门店需求排期；E 类必须在发布前完成。
