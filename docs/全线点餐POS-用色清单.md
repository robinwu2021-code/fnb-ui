# 全线点餐 POS · 用色清单（按原型采集）

> 状态：2026-10-24 · 默认配置：墨黑皮肤 · 黑白灰色系 · 浅色
> 来源：① `proto.css` POS 段逐条规则采集「哪个令牌用在哪个组件的哪个属性」；② 在原型里实测桌台、点餐、结账、订单卡片四个画面，统计每种颜色的面积占比与出现位置（抽样四屏，未遍历全部画面）。
> 规则见《[设计规范（布局·形状·色系）](全线点餐POS-设计规范（布局·形状·色系）.md)》第三节；色阶与生成见《[色彩体系](全线点餐POS-色彩体系.md)》。

## 二、实测：四个画面各用了哪些颜色

面积 = 该颜色所有元素的外接矩形之和 / 画面面积（嵌套会重复计，白底超过 100% 属正常，只看相对大小）。

### 2.1 桌台

| 颜色 | 面积 | 位置 |
|---|---|---|
| 白 | 底 | 系统栏、三栏面板、白色窄底 |
| gray-50 | 24.8% | 空闲桌卡、详情清单、muted 按钮 |
| gray-100 | 10.4% | 占用中的桌卡（用餐中、待点餐、已预订） |
| **琥珀块 #FFE3CB** | **7.5%** | 待结账、部分支付、待清台、超时的桌卡 |
| gray-200 | 2.2% | 页签当前项、导航当前项、当前桌 |
| 墨 | 1.4% | 「加菜」主按钮 |
| 浅红 #FECDC6 | 0.2% | 「清台」危险按钮 |
| 字 | — | 次要 gray-600 74 处 · 墨 66 处 · 琥珀字 6 处（状态标签）· gray-400 3 处 · gray-700 1 处（等待中）· 红 1 处（清台） |

一屏 9 种底色、7 种字色；有色相的只有琥珀和红。

### 2.2 点餐

| 颜色 | 面积 | 位置 |
|---|---|---|
| 白 | 底 | 面板、待下单白卡、步进器、白色窄底 |
| gray-50 | 26.1% | 未点的菜品卡、搜索框、筛选、分段轨道、块色清单 |
| gray-200 | 1.3%（改前 25%） | 页签 / 导航 / 筛选 / 分段当前项 |
| gray-100 | 41.4% | 已点的菜品卡（6 张）；照片位的占位底（被照片盖住，不可见） |
| 墨 | 1.4% | 份数角标、导航已点小圆点、「结账」主按钮 |
| gray-300 | 0 | 分类小方块已隐藏 |
| 字 | — | gray-600 65 处 · 墨 48 处 · 白 8 处（角标、主按钮）· gray-400 3 处（原价、不可用券）· 琥珀 2 处（催菜中） |

点餐页灰面积最大（已点 6 道是 gray-100），照片是唯一的大面积颜色。

### 2.3 结账

| 颜色 | 面积 | 位置 |
|---|---|---|
| 白 | 底 | 账单清单里的优惠行、收款区、白色窄底 |
| gray-50 | 32.8% | 块色清单、输入框、快捷金额、按键 |
| gray-200 | 1.0% | 页签当前项、选中的支付方式、选中的快捷金额 |
| 墨 | 1.0% | 「确认收款」键 |
| gray-100 | 0.9% | 功能键 |
| 品牌色 × 6 | 各 0.1% | 支付方式图标 |
| 字 | — | gray-600 45 处 · 墨 43 处 · 白 9 处 · gray-400 1 处 |

结账页几乎没有信号色：待付金额靠 32 号墨字，不靠颜色。

| gray-100 | 29.3% | 进行中、已完成等常态订单卡 |

| **琥珀块 #FFE3CB** | **8.8%** | 待结账、部分支付的卡 |

## 三、字面量（不走令牌的颜色）

| 位置 | 值 | 说明 |

## 四、从清单看到的问题

| # | 发现 | 建议 |
|---|---|---|
| 1 | 点餐页 gray-200 占 25%：已点的菜和当前项用同一档，6 张已点卡让「当前项」的分量被稀释 | **已改**：已点 = gray-100 + 墨色角标，gray-200 只给当前项；gray-200 面积 25% → 1.3% |
| 2 | 无图菜品大字位 gray-100，比未点卡（gray-50）深，像「已选」 | **已改**：`--c-slot-bg` = gray-50，字墨 |
| 3 | 琥珀块在桌台、订单页各占 7–9%，是信号，面积合理 | 不改；但要处理的桌超过一屏一半时信号失效，属业务问题 |
| 4 | 组合支付图标底写死 #5E5E5E（接近 `--sh-sub`） | **已改**：`--c-control-off` gray-500；`--sh-sub` 只做字 |
| 5 | 结账页危险色只剩筛选计数和「反结账」，没有信号色；「待收」只靠字号 | 符合规则（待收不是异常） |
| 6 | 分类小方块 gray-300 在黑白灰下几乎看不见 | **已改**：黑白灰下不显示（`[data-tone="quiet"] .dn-mark{display:none}`），多色下照旧 |

1、2、4、6 已改（2026-10-24）；3、5 不改。
