# 全线点餐 POS · 线框改色块：问题清单

> 状态：已按建议组合实施（2026-10-23）：卡片未选浅灰底块；菜品已点 gray-200（做法 B）；当前桌、订单卡、活动卡选中墨底白字（做法 A）；列表 / 表格当前行 gray-100；危险按钮浅红底红字；勾选框实心浅灰块；会员卡、待下单组浅底块。A1–A4、B1–B3、C1–C4 全部处理。
> 对象：`prototypes/bapp/pos-ui.html`、`proto.css`（当前 v12：白底少灰、选中墨底白字、结单区 v4）
> 方法：在原型里逐个画面采集所有带 `box-shadow` 内描边、`border`、`outline` 的元素（点餐有图上下 / 左右 / 无图、桌台、选桌弹窗、订单列表 / 卡片、结账、菜品、会员、批量模式），再对照 `proto.css` 找到样式来源。

## 一、结论

点餐和桌台页的「深色线框」都来自同一个设计：**v10 去灰后，卡片是白底放在白面板上，本身没有边界，于是「选中」只能用墨色 2px 内圈来表达**。墨黑皮肤下主色就是墨色，所以已点的菜、当前桌都变成了一个个黑框；点餐页常态下一屏有 6 个。

要改成色块，需要同时做两件事：
1. **卡片本身要有一块底**（否则去掉黑框后，选中和未选中都是一片白，分不出来）；
2. **选中改成换底色**，不再加框。

## 三、选中态改成色块：两种做法

| | 做法 A：墨底白字（推荐用于桌台、订单卡） | 做法 B：深一档灰底（推荐用于菜品卡） |
|---|---|---|
| 未选 | 浅底块 gray-50 | 浅底块 gray-50 |
| 选中 | 整块墨底（gray-900），文字和图标白色 | 整块 gray-200 底，菜名加粗；份数角标墨色 |
| 优点 | 一眼最清楚；和导航、分段、筛选的选中一致 | 一屏可能有很多已点的菜，不会出现一片黑块；图片仍是主角 |
| 缺点 | 一屏多个选中时太重（点餐页常态 6 张已点） | 对比较弱（gray-50 → gray-200 约 1.24:1），靠份数角标补足 |

**建议组合**：菜品卡用 B（已点可能很多），桌台当前桌、订单卡选中、活动卡选中用 A（一屏只有一个），列表 / 表格当前行用 gray-100。

## 四、需要确认

1. 卡片（菜品、桌台、订单）**未选时改成浅灰底块**（gray-50）——这会让点餐页、桌台页的灰面积回升一些（预计点餐 +25%、桌台 +30%）。不做的话，去掉线框后卡片没有边界。
2. 选中态按第三节**建议组合**（菜品 B、桌台和卡片 A、列表行 gray-100）。
3. 危险按钮（清台、反结账、退菜）是否也改成浅红底 + 红字的色块；组件方案里原本规定为「描边墨字」。
4. 勾选框的未选态改成实心浅灰块，不用描边（开关的关闭态本来就是实心灰轨道，不用改）。
