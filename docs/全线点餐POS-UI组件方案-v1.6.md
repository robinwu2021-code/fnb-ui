## 一、这一版的方向

**按钮、选中、当前对象和状态都不用黑色。** 墨色 #181A1C 只留给正文、标题和金额这类文字。选中和当前对象用主题色浅底加主题色描边；浮层改为白底或深灰。

起因：v1.5 里仍有几处是墨色实心或墨色描边，桌台的当前桌 A03 最明显。另外 v1.5 页面上能选「墨黑」皮肤，选了之后主按钮、份数角标也都变成黑色。

## 二、改了什么

| 位置 | v1.5 | v1.6 |
|---|---|---|
| 选择类选中（筛选、规格、支付方式、券、快捷金额） | 白底 + 2px 墨色内圈 + 勾 | 松绿浅底 pine-100 + 松绿字 pine-700 + 1.5px 松绿内圈 + 勾 |
| 导航类选中（工作台页签、分类、二级菜单） | gray-200 + 墨字 | 松绿浅底 + 松绿字 600 |
| 分段选中 | 白滑块 + 墨字 | 白滑块 + 松绿字 |
| 列表里选中的行（订单列表、批量勾选） | gray-200 | 松绿浅底；gray-200 上的松绿状态字只有 4.37:1 |
| 当前桌、选中的订单卡 | 墨底白字 | 松绿浅底 + 2px 松绿内圈；桌号松绿，卡里的状态标签保留自己的颜色 |
| 状态「进行中」（用餐中、制作中、营业中） | 墨色图标和字 | 松绿图标和字，表示「正在发生」 |
| 状态「预约」「暂存」 | 墨色 | gray-700 |
| 操作菜单 | 墨色底白字 | 白底 + 一层浅阴影（浮在面板上）；危险项红字；不可用项次要字色 |
| Toast | 墨色底 | 深灰 gray-800 |
| 授权码圆点、色板选中圈 | 墨色 | 松绿 |
| 按钮和入口里的图标（系统栏、次按钮、快捷操作、优惠行、键盘功能键） | 墨色 | gray-700；按钮文字仍是墨色 |
| 规格选项的形状 | 全圆胶囊 | 12 圆角块，勾在右上。两行内容（名称 + 加价）放在胶囊里太挤；全圆只留给单行的筛选、分段、快捷金额、横排分类 |
| 已点菜品 | 松绿浅底 + 墨色菜名 | 松绿浅底 + 松绿菜名；份数角标仍是松绿实心 |
| 皮肤 | 含墨黑 | 去掉墨黑：它的主题色就是黑色，和本版方向矛盾。旧存档里选过墨黑的，打开 v1.6 时改为松绿 |

不变的部分：主按钮是松绿实心，一屏一个；次按钮是 gray-150 底加墨字；危险操作是红字，二次确认里才是红色实心；待处理是琥珀，异常是红；形状、间距、灰阶同 v1.5。

## 三、颜色搭配（v1.6）

| 用途 | 底 | 字 / 图标 | 形状信号 |
|---|---|---|---|
| 主操作 | pine-700 #306F5F | 白 | 8 圆角 |
| 选中（选择类） | pine-100 #DFF2EC | pine-700 | 1.5px 松绿内圈 + 勾；单行全圆，两行 12 |
| 选中（导航类） | pine-100 | pine-700，600 | — |
| 当前对象 | pine-100 | 墨字，桌号 pine-700 | 2px 松绿内圈 |
| 已点菜品 | pine-100 | 菜名 pine-700 | 松绿实心份数角标 |
| 进行中状态 | — | pine-700 | 图标 + 文字 |
| 待处理 | 琥珀块（60%） | warning-800 | 图标 + 文字 |
| 异常 | 红浅底 | danger-700 | 图标 + 文字 |
| 常态（已完成、已关闭等） | — | 次要字色 | 图标 + 文字 |
| 次按钮、控件 | gray-150 | 墨字，图标 gray-700 | 8 圆角 |

松绿的实心、选中、当前对象、已点四种用法分别靠「实心」「浅底 + 描边 + 勾」「浅底 + 粗描边」「浅底 + 角标」区分，不靠深浅不同的绿色。

## 四、抽查（2026-10-24，1440 宽，设备 1280 × 800，松绿 · 黑白灰 · 紧凑）

UI 原型抽查了点餐、桌台、结账、订单四个画面，外加点餐画面的「更多」操作菜单；组件页扫描了全部样张。

| 检查项 | 结果 |
|---|---|
| 墨色实心块、墨色描边 | 原型四个画面和操作菜单里都是 0；组件页也是 0（色板选中圈已改为松绿） |
| 按钮和入口里的墨色图标 | 0 |

| 控制台 | 无报错 |
